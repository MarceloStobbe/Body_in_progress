# Body in Progress

A professional-grade, mobile-first SaaS fitness web application built with Python Flask and PostgreSQL, featuring dynamic theme customization, dual stopwatches, hydration tracking, and weekly analytics reports.

## Tech Stack
- **Backend:** Python, Flask, Flask-SQLAlchemy
- **Database:** PostgreSQL (SQLite for local testing)
- **Frontend:** HTML5, CSS3 (CSS Custom Properties for dynamic themes), JavaScript
- **Testing:** Pytest

## Setup Instructions
1. Create a virtual environment: `python -m venv venv`
2. Activate environment: `source venv/bin/activate` (Mac/Linux) or `venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt`
4. Run application: `python run.py`
5. Run tests: `pytest`
